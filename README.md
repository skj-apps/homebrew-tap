# homebrew-tap

Homebrew tap for [SKJ Apps](https://skjapps.com/) Mac apps.

## Install

```sh
brew tap skj-apps/tap
brew install --cask mistbar
```

Or in one line:

```sh
brew install --cask skj-apps/tap/mistbar
```

## Apps

| Cask | Description |
|------|-------------|
| `mistbar` | Menu-bar declutter tool with clipboard, mail, notes, and AI-usage tracking — [mistbar.app](https://mistbar.app/) |

MistBar auto-updates via Sparkle after install.
